# دليل الاستخدام

## تشغيل الواجهة

من داخل المجلد الرئيسي للمشروع وبعد تفعيل البيئة الافتراضية، نفّذ:

```bash
python src/checker.py
```

تعتمد الأداة على قائمة تفاعلية في الطرفية. اختر نوع الفحص والمنصة وطول الاسم أو النمط المطلوب، ثم ابدأ الفحص. تتولى الأداة عرض التقدم وحفظ النتائج وفق الخيار الذي تحدده الواجهة.

## تشغيل البوت

لتمكين وظائف Telegram، عرّف `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` قبل التشغيل. ويمكن تحديد قائمة المحادثات المسموح لها باستخدام `TELEGRAM_ALLOWED_CHAT_IDS`، مع فصل المعرفات بفواصل:

```bash
export TELEGRAM_BOT_TOKEN="توكن_البوت"
export TELEGRAM_CHAT_ID="123456789"
export TELEGRAM_ALLOWED_CHAT_IDS="123456789,987654321"
python src/checker.py
```

يجب اختبار البوت في محادثة تملكها أو تديرها. لا تضع التوكن في README أو في أي ملف متتبع بواسطة Git.

## قراءة النتائج وتصديرها

تتيح القائمة عرض الملفات المحفوظة وتحليل الكلمات الشائعة وتصدير النتائج. احتفظ بملفات النتائج محليًا، ولا ترفعها إلى المستودع إذا كانت تحتوي على أسماء مستخدمين أو بيانات تشغيلية حساسة.

## السجلات والإحصائيات

يكتب التطبيق سجل التشغيل في `logs/checker.log` افتراضيًا. ويخزن إحصائيات استخدام البوت في `bot_usage_stats.json`. لتغيير المواقع:

```bash
export TG_CHECKER_LOG_DIR="var/logs"
export TG_CHECKER_STATS_FILE="var/data/bot-usage.json"
```

يعرض أمر `/stats` في البوت إحصائيات الأوامر والرسائل عندما يكون البوت مفعّلًا ومصرحًا للمحادثة المستخدمة.

## تشغيل الاختبارات

```bash
python -m unittest discover -s tests -v
```

ولفحص الصياغة مباشرة:

```bash
python -m py_compile src/checker.py src/config.py src/models.py
```

## مشكلات شائعة

إذا ظهر خطأ `ModuleNotFoundError`، فعّل البيئة الافتراضية وثبّت التبعيات من جديد:

```bash
python -m pip install -r requirements.txt
```

إذا فشل الاتصال بـ Telegram، تحقق من صحة التوكن ومعرف المحادثة والاتصال بالإنترنت، ثم راجع السجل دون مشاركة محتواه إذا كان يتضمن بيانات تشغيلية.
