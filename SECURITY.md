# Security Policy

## Usage Guidelines

- Use this tool only with accounts and services you own or have permission to use
- Respect platform terms of service and rate limits
- Do not abuse or overload target services
- Use responsibly and ethically

## Important Notes

- Do not commit sensitive data (tokens, credentials, collected usernames)
- Keep your configuration files private
- Report security issues to the repository owner

## Disclaimer

This tool is for educational and personal use only.
The developer is not responsible for any misuse.
