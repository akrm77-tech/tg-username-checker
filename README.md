# 🚀 WORMGPT - Ultimate Username Scanner v7.0

أداة احترافية ومتقدمة لفحص توفر أسماء المستخدمين عبر منصات التواصل الاجتماعي المتعددة مع دعم الإشعارات عبر تيليجرام.

## ✨ الميزات
- 🔍 فحص متعدد المنصات (Instagram, Twitter, TikTok, Telegram, إلخ).
- 🤖 دعم كامل لبوتات تيليجرام للإشعارات.
- ⚡ سرعة عالية باستخدام Threading.
- 🛡️ دعم البروكسي لتجنب الحظر.
- 📊 تقارير مفصلة وإحصائيات دقيقة.

## 📁 هيكلية المشروع
- `src/`: يحتوي على الكود المصدري الرئيسي (`checker.py`).
- `docs/`: ملفات التوثيق والشرح.
- `requirements.txt`: ملف التبعيات.

## ⚙️ التثبيت
```bash
pip install -r requirements.txt
```

## 🚀 التشغيل
```bash
python src/checker.py
```
