# Username Scanner Tool

أداة لفحص توفر أسماء المستخدمين على تيليجرام مع إمكانية إرسال النتائج عبر بوت

## 🛠️ الميزات
- فحص أسماء مستخدمين تيليجرام
- توليد أسماء عشوائية بطول محدد
- عرض الإحصائيات كل 30 اسم
- تقييم جودة الأسماء المكتشفة
- إرسال النتائج إلى بوت تيليجرام (اختياري)
- دعم تعدد الخيوط للسرعة

## 📁 هيكلية المشروع
```
src/
├── checker.py    # الكود الرئيسي
└── utils/        # أدوات مساعدة

```

## 📋 المتطلبات
- Python 3.6+
- مكتبة requests
- مكتبة colorama
- مكتبة threading (مدمجة)

## 🧾 التسجيل وإحصائيات استخدام البوت

يكتب البرنامج الأحداث والأخطاء في `logs/checker.log` باستخدام تدوير تلقائي للملف، مع الاحتفاظ بثلاثة ملفات احتياطية بحد أقصى. يمكن تغيير مجلد السجل عبر المتغير `TG_CHECKER_LOG_DIR`.

عند تشغيل البوت، تُحفظ إحصائيات الاستخدام في `bot_usage_stats.json`. يعرض الأمر `/stats` عدد الأوامر المستلمة والمسموحة والمرفوضة، والأوامر غير المعروفة أو الفاشلة، والرسائل المرسلة والفاشلة، وآخر نشاط، إضافة إلى أكثر الأوامر استخدامًا. يمكن تغيير مسار ملف الإحصائيات عبر `TG_CHECKER_STATS_FILE`.

لا تُسجَّل توكنات البوت أو محتوى الأسرار في السجل. ولتقييد الأوامر على محادثات محددة، استخدم `TELEGRAM_ALLOWED_CHAT_IDS` مع فصل المعرفات بفواصل.
